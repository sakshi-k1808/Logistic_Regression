# Logistic_Regression

This repository contains a Jupyter Notebook that demonstrates the implementation of **Logistic Regression** for binary classification. The notebook walks through the entire pipeline including data preprocessing, model training, evaluation, and visualization of results.

##  Features

- Importing and exploring the dataset
- Data preprocessing (cleaning, encoding, normalization, etc.)
- Logistic regression model training using `scikit-learn`
- Model evaluation using accuracy, confusion matrix, ROC curve, and more
- Data visualization using libraries like `matplotlib` and `seaborn`
